# 어디버려 (odibury) ♻️

> 이거 **어디에·어떻게·얼마에** 버려? — 우리동네 기준 분리배출·대형폐기물 정보를 3초에 판단해주는 서비스.

## 무엇을 하는가

지자체마다 제각각인 분리배출 규칙과 대형폐기물 수수료가 사방에 흩어져 있어,
"이거 버려도 되나? 우리동네선 얼마지? 어떻게 신고하지?"를 매번 검색해야 하는 페인을 없앤다.

- **동네 선택** → **품목 검색** → **수수료 + 배출방법 + 신고 링크**를 한 화면에.
- 실제 신고·결제는 각 지자체(또는 여기로/빼기 같은 앱) 시스템으로 **딥링크 토스**.
- 우리는 결제를 소유하지 않는다. **정보·판단 레이어**만 소유한다.

## 스코프 원칙

- **저작권 클린**: 사실 데이터(지자체 조례 수수료·품목) + 크라우드소싱만 사용.
- **결제 없음**: 신고/납부는 지자체 시스템으로 링크만 연결.
- **한 동네부터**: v1은 관악구 하나로 완성품. 파편화가 곧 진입장벽(해자).

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · shadcn/ui · (예정) Supabase

```bash
npm run dev     # 개발 서버
npm run build   # 프로덕션 빌드 + 타입체크 게이트
npm run lint    # ESLint
```
